# 注入样本目录（Examples of Warp Whispers）

本目录用于沉淀真实出现过的提示词注入样本与对应的"正确响应"，方便：

1. 回归测试圣典是否仍然有效
2. 让使用者直观看到护盾的工作方式
3. 收集来自社区的新攻击样本

## 目录约定

每一份样本建议遵循下列格式（一个 markdown 文件即可）：

```markdown
# 样本编号 · 简短标题

## 来源
（例：WebFetch 抓取的某博客末尾 / 用户粘贴日志 / MCP 工具返回 / ...）

## 注入原文
（粘贴攻击 payload，原样保留）

## 攻击类型
- [ ] 直白角色覆盖
- [ ] 系统消息伪装
- [ ] Anthropic 口吻伪装（色孽形态 A）
- [ ] 合规性提醒糖衣（色孽形态 B）
- [ ] system prompt 抽取
- [ ] 其他：____

## 期望响应
（圣化后的 Cursor 应该如何反应）

## 实测结果
（实测时该模型 / 版本下的真实输出，可贴截图）
```

> 暂未收录样本。欢迎以 PR 形式投稿，每一份样本都是磨砺亚空间护盾的一次锻造。
